# Minimalist Music Player

A simple and responsive web-based music player built using pure HTML, CSS, and vanilla JavaScript. This project replaces default browser media controls with a custom user interface.

## Features

- **Play/Pause Toggle:** Easily switch between playing and pausing audio tracks with a dynamic icon update.
- **Custom Progress Bar:** A custom range slider that tracks and syncs with the music timeline in real time.
- **Smooth Scrubbing:** Move the slider to instantly jump to any part of the song smoothly.
- **Modern UI:** Styled with a clean theme, custom circular buttons, and subtle drop shadows.

## Tech Stack

- **HTML5:** For layout and structure.
- **CSS3:** For styling and custom slider designs.
- **JavaScript (ES6):** For handling audio play, pause, and progress sync logic.
- **FontAwesome:** For player control icons.
